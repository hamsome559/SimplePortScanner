# SimplePortScanner
Port scanner as simple as it can get. The comments on the code is unimportant. Its just for my personal use for me to understand it better

The most common ports you can find when scanning this is:
port 80 => "HTTP"
port 443 => "HTTPS"
port 22 => "SSH"
port 21/20 => "FTP"
port 25 => "SMTP"

the most common ports are between 1 and 1025 hence why I opted for that over 65535.
